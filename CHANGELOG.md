# Changelog

## 1.0 — 2026-10-13

First public release of this maintained version of UmamiBar.

- Native macOS menu bar dashboard with an opaque surface and compact black logo.
- All-websites and selected-websites modes; a single selected site opens expanded.
- Umami-style, overlaid visitor/pageview bars with a fixed 24-hour timeline for Today.
- Top pages, referrers, live visitors and comparison changes.
- Self-hosted and Cloud connections, Keychain credential storage and in-memory login tokens.
- Refresh scheduling, launch-at-login settings, error recovery and stale-response protection.
- English and Simplified Chinese interfaces.
- Apple silicon download signed with Developer ID and notarized by Apple; macOS 26+ required.
